取景台

运行与快捷键

在 64 位 Windows 10（1607 或更高版本）或 Windows 11 上双击取景台.exe。软件运行时，全局 F1 和 F2 在其他应用窗口内也有效，退出后释放。若系统限制全局快捷键，可使用主窗口的操作按钮。

F1 截图

默认使用框选模式。可以在任意显示器上按住鼠标左键拖动。松开鼠标，标注窗口会直接出现在截图所在屏幕的中央。跨屏框选时，窗口出现在选区占比最大的屏幕上。全屏截图和滚动截图完成后也会在截图所在屏幕弹出标注窗口。
选择“红色方框”后拖动绘制。选择“红色箭头”后，从起点拖到需要指向的位置。选择“红色文字”后单击图片输入文字，Shift + Enter 换行。
使用“选择”工具单击标注并拖动，可移动方框、箭头或文字。拖动方框角上的控制点可调整大小，拖动箭头任一端可改变长度或方向。双击文字可修改内容。
把鼠标移到方框、箭头或文字上，滚轮向上加粗，向下变细。绘制方框或箭头时也可以滚动调线宽。文字默认使用常规字重，可用滚轮切换细体、常规和粗体，输入文字时同样有效。按 Ctrl + Z 可撤销对已完成标注的粗细调整。
Delete 删除选中的标注，Ctrl + Z 撤销上一步操作。Esc 取消正在进行的拖动或文字编辑。没有正在编辑的内容时，Esc 取消本次截图。
按 Enter 或点击“复制到剪贴板”完成，随后在目标应用中按 Ctrl + V 粘贴。

滚动截图

在默认框选模式下按 F1，在框选前按 S，然后拖动鼠标选择网页、文档或聊天记录中要截取的滚动区域。也可以在主窗口选择“截图 → 滚动截图”，点击“开始滚动截图”。
松开鼠标后，选区保持原亮度，选区外侧有细边线，周围屏幕略微变暗。可以照常点击或滚动。完成或取消后，屏幕亮度恢复。
将鼠标移入选区，缓慢向下滚动。控制条显示已拼接的高度。选择内容区域更容易拼接，尽量避开固定侧栏、视频和不断刷新的内容。如果提示未接上，稍向上滚回刚才的内容，再慢慢向下。
点击“完成”或使用控制条标出的 Enter 快捷键进入标注；点击“取消”或按控制条标出的 Esc 放弃。旧系统在全屏选区内无法显示控制条时，可用取景台的托盘菜单完成或取消。
在标注窗口把鼠标移到空白处滚动，或拖动右侧滚动条浏览长图。按 Enter 复制完整图片。长图只在内存和剪贴板中处理。单张长图最多 30,000 像素高、4,000 万像素，达到上限后可以完成当前截图。

F2 录屏

首次按 F2 开始录制鼠标所在的显示器。屏幕上方会先显示“正在准备录屏”，录制开始后显示红点和计时。再次按 F2 或点击状态条上的“停止”即可结束，看到“录屏已复制”后可粘贴视频。
要只录一部分，可先在主窗口选择“录屏”和“框选区域”。也可点击“开始录屏”启动。如果键盘的 F2 同时控制亮度或音量，可使用 Fn + F2。
框选录屏时，亮着的区域就是视频范围，主屏和扩展屏上选区以外的部分会略微变暗。停止录屏后，周围恢复原亮度。全屏录制时保留整个桌面的正常亮度。
状态条优先显示在录制屏上方。当系统无法将状态条排除在录制画面之外时，会尝试放在录制区域外或另一块屏幕。若所有屏幕都在录制范围内且系统不支持排除窗口，准备提示将短暂显示，随后可通过系统托盘或 F2 停止。
默认开启“录制麦克风”。按 F2 开始后，对着 Windows 默认麦克风讲话，声音会和画面一起录入同一个 MP4。录制中，计时条上的麦克风图标表示正在收音。需要无声视频时，在录屏页关闭“录制麦克风”，取景台会记住这个选择。要换用耳机麦克风，请在开始前到 Windows 的“设置 → 系统 → 声音 → 输入”选择设备。
如果提示麦克风访问被拒绝，请在 Windows 设置中搜索“麦克风隐私设置”，允许桌面应用访问麦克风，然后再录。录制期间若设备断开，取景台会提前结束并保留已录下的片段。
视频采用 H.264 编码，目标帧率为每秒 20 帧。麦克风音轨采用 AAC 编码。过大的选区会按比例缩小至系统编码器支持的范围。

剪贴板

截图只复制图片到剪贴板。录屏默认启用“聊天附件（临时 MP4）”。看到“录屏已复制”后，在 i讯飞等支持粘贴文件的聊天框中按 Ctrl + V，检查附件和收件人后自行发送。
聊天附件模式会将一份 MP4 写入当前用户临时目录中的 FrameDesk-VideoAttachments 文件夹。取景台在启动时和运行期间每小时清理超过 24 小时的临时录屏；若程序已退出，会在下次启动时清理。正在使用且无法删除的文件会在之后重试。
如果希望录屏只保存在内存，在主窗口选择“录屏”并关闭“聊天附件（临时 MP4）”。取景台会记住这个选项。纯内存模式需要目标应用支持虚拟视频文件，请在粘贴前保持取景台运行。
复制新内容会替换当前剪贴板内容。Windows 剪贴板历史记录和云同步会跳过取景台的捕获内容。

从源码构建

解压整个源码包后双击 build.cmd。脚本使用 Windows 自带的 64 位 .NET Framework C# 编译器，在同一目录生成 FrameDesk.exe。运行时使用系统自带的 Windows Media Foundation 编码器。
