# FrameDesk（取景台）

取景台是一款 Windows 截图和录屏工具。支持多显示器框选、滚动长截图，以及可移动和修改的红框、箭头和文字标注。

## 下载运行

适用于 64 位 Windows 10（1607 或更高版本）和 Windows 11。下载后双击 `FrameDesk-1.10.0-win-x64.exe` 即可运行。保持取景台开启即可使用全局快捷键。[下载取景台 1.10.0（Windows 64 位）](https://github.com/qqqjjjwww/FrameDesk/releases/download/v1.10.0/FrameDesk-1.10.0-win-x64.exe)

| 操作 | 用法 |
| --- | --- |
| 框选截图 | 按 **F1**，拖动鼠标框选。松开后，标注窗口会出现在截图所在的屏幕上。 |
| 滚动截图 | 默认框选模式下按 **F1**，再按 **S**。框选后在选区内缓慢向下滚动，点「完成」进入标注。 |
| 查看捕获范围 | 滚动截图和框选录屏期间，选区保持原亮度，周围屏幕略微变暗。可照常点击、滚动或打字。 |
| 复制截图 | 在标注窗口按 **Enter**，然后在目标应用中按 **Ctrl+V** 粘贴整张图片。 |
| 滚轮调整标注粗细 | 指向方框、箭头或文字，滚轮向上加粗、向下变细。文字支持细体、常规和粗体。长图的空白处可滚动浏览。 |
| 录屏 | 按 **F2** 开始，再按 **F2** 停止。默认复制为临时 MP4 附件，可粘贴到支持文件的聊天框。 |
| 麦克风讲解 | 录屏页默认开启「录制麦克风」，使用 Windows 默认输入设备。关闭后可录制无声视频。 |

截图仅在内存和剪贴板中处理。录屏默认生成临时附件，程序运行时会定期清理超过 24 小时的临时录屏。也可以在录屏设置中关闭「聊天附件」，使用纯内存模式。[完整使用说明](./使用说明.txt)

## 从源码构建

在 64 位 Windows 上打开 `src` 目录，双击 `build.cmd`，构建成功后会在同一目录生成 `FrameDesk.exe`。构建脚本使用 .NET Framework 自带的 C# 编译器。[查看源码](./src/)
